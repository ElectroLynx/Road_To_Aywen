# Road To Aywen
## Fait par @ferdepowerz pour le Hackathon de la communauté de Aywen.

# Qu'est ce que c'est ?
Tu incarnes Root (la mascotte de Aywen). Un jour, il se trouve que Aywen t'oublie sur le rebord de la fenêtre et tu tombes. Ton objectif ? Te venger de Aywen en pleine vidéo. Mais comment faire ? Pour cela tu vas devoir faire des parcours de plus en plus compliqué jusqu'à atteindre son setup. Allors lance toi dans l'aventure !

# Comment tester ?
En téléchargeant la dernière version du jeu dans Releases. Il inclut un installateur .exe
> [Releases](https://github.com/ElectroLynx/Road_To_Aywen/releases/tag/releases)

# Comment avoir sa propre version ?

- Avoir GDevelop 5 installé sur son ordinateur
- Le code source de Road To Aywen

1. Ouvrir le dossier du code source avec GDevelop 5. Tout se configurera automatiquement.
2. Modifier !
